# web_programs_trening

Тренировочный дневник FitLog (PHP): дневник тренировок, история, прогресс по упражнениям, экспорт отчётов.

## Требования

- PHP 7.4+ (рекомендуется 8.x) с PDO
- Хостинг: MySQL (pdo_mysql), локально для разработки — SQLite (pdo_sqlite)

## Данные

Данные хранятся в **БД** (нормализованная схема: users, workouts, workout_exercises, workout_sets, registration_log).
Справочник упражнений — файл `data/exercises.json` (это не личные данные и он в git).

Схема создаётся автоматически при первом обращении.

## Локальный запуск

1. Убедитесь, что включён `pdo_sqlite`. Без php.ini можно указать драйвер при запуске:

   ```sh
   php -d extension=php_pdo_sqlite.dll -d extension=php_sqlite3.dll -S 127.0.0.1:8081 -t .
   ```

   (пути к DLL — из папки `ext` вашего PHP)

2. `config.php` уже настроен на SQLite (файл `data/fitlog.sqlite`, не в git) — работает из коробки.

## Деплой на хостинг (MySQL)

1. Скопируйте `config.example.php` в `config.php` и впишите доступы MySQL:
   `driver => 'mysql'`, host (обычно `localhost`), имена БД/пользователя и пароль из панели хостинга.
   `config.php` в git не попадает — создаётся только на сервере.
2. Загрузите файлы проекта на хостинг (FTP).
3. База создастся сама при первом запросе. Если нужно перенести текущие данные:
   - загрузите в `data/` свои `users.json` и `workouts.json` (их в git нет),
   - откройте `http://site/migrate.php` — данные перенесутся в MySQL один раз,
   - **после миграции удалите `migrate.php` с сервера**.
4. Проследите, чтобы папка `data/` была доступна для записи (для файла справочника упражнений).
